1. Чистый слой domain & ontology Модули в assets/domain/ и assets/ontology/ не обращаются к DOM/window и импортируются напрямую в node --test.
2. Единый источник правды Правки вносятся только в openrig/ и landing/; папка public/ генерируется командой npm run sync:public.
3. Неблокирующая аналитика FleetIntelligenceEngine принимает снапшоты через setImmediate с изоляцией сбоев детекторов.
4. Действия только по причине Все 4 UI-поверхности берут кнопки из ACTION_DEFINITIONS; у здорового idle-узла 0 write-back кнопок.
