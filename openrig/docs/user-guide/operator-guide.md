# Руководство оператора — OpenRig Neural Command Deck

Руководство для человека-оператора, управляющего разработкой через интерфейс **OpenRig Neural Command Deck** (`http://127.0.0.1:7440`).

---

## 1. Запуск и подключение

Дашборд состоит из лёгкого сервера телеметрии и веб-интерфейса:

```bash
# Запуск сервера телеметрии в терминале хоста:
node ~/www/agenticos/openrig/server.mjs
```

После старта откройте в браузере: **`http://127.0.0.1:7440`**.  
Если сервер временно остановлен, дашборд переключается в **SNAPSHOT MODE**, сохраняя последний снимок данных.

---

## 2. Расшифровка индикаторов состояния агентов

На карточках узлов топологии отображаются светодиодные маркеры активности:

| Индикатор | Статус | Что происходит | Что делать оператору |
|---|---|---|---|
| 🟢 `WORKING (N)` / `❤️` | **В работе** | Агент исполняет команду или прогон тестов, пульсирует сердце. | Не вмешиваться, процесс идёт автономно. |
| 🔵 `IDLE` / `Zzz...` | **Спит (Покой)** | Задача завершена, агент ожидает назначения нового конверта в очереди. | Штатный режим ожидания. |
| ⏳ `HELD (N с wake)` | **Пауза с таймером** | Агент закончил раунд и взвёл таймер пробуждения (например, обход раз в 15 минут). | Здоровое состояние, проснётся сам по таймеру. |
| 🟠 `PARKED (N)` | **Запаркован с долгами** | Узел остановлен, но за ним числятся незакрытые задачи **без** активного таймера. | Требует внимания: проверить `rig parked` и пнуть узел сообщением `rig send`. |
| 🚨 `NEEDS INPUT` | **Ждёт человека (P0)** | Агент упёрся в подтверждение прав (Terminal Gate / Permission Prompt) или вопрос. | **Кликнуть на узел**, посмотреть экран tmux и нажать `✅ 1 (Proceed)` или `y`. |

## 3. Работа с Радаром внимания («Кто → Кого → Зачем ждёт»)

Левая колонка экрана сортирует все текущие задержки в контуре по приоритету:

```
[ P0 • ЖДЁТ ЧЕЛОВЕКА ] — Агент заблокирован терминалом (красный бордер)
[ P1 • В РАБОТЕ ]      — Задача выполняется исполнителем (зелёный бордер)
[ P2 • СКОРО РОТАЦИЯ ] — Нагрев контекста выше 70% (оранжевый бордер)
[ P2.5 • PARKED ]      — Останов с долгами без таймера (янтарный бордер)
```

- Клик по карточке в радаре подсвечивает связанный узел на карте и открывает его паспорт.

---

## 4. Паспорт узла и встроенный терминал

Правая колонка служит рабочим пультом выбранного агента:

1. **⚠️ Блок «Тревожные знаки»:**
   - **`🔄 Сжатий / свапов`**: показывает общее число прошедших компакций сессии. Если число >5, узел подвергается интенсивной перезаписи контекста.
   - **`Темп выгорания`**: рассчитывает скорость расхода окна в % в час и прогнозирует время до порога 75%.
   - **`Возвраты QA` (для кодеров)**: показывает средний круг приёмки (`Avg кр`) и историю раундов `[1 кр] [2 кр]`. Если средний круг >2.0, точность кодера считается сниженной.
2. **📜 Блок «Инструкция и контракт» (Табы):**
   - **`📋 ПРАВИЛА И ГРАНИЦЫ`**: список обязанностей агента и строгие запреты (например, кодерам запрещено пушить напрямую и использовать shell-пайпы `\|`).
   - **`🔄 ХАРНЕС & ФОЛБЭК`**: модель, текущий профиль биллинга (ChatGPT Pro 100 / APIKO Terra / GLM) и резервный маршрут.
   - **`🧠 ПАМЯТЬ RECAP`**: выжимка безопасной контрольной точки из `RECAP.md`.
3. **🖥️ Встроенный терминал:**
   - Показывает последние 32 строки живой консоли `tmux`.
   - Кнопка **`🔴 AUTO-FOLLOW`**: автоматически обновляет экран каждые 2 секунды, пока агент находится в статусе `WORKING`.
   - Кнопка **`⛶ 80 строк`**: открывает полноразмерное модальное окно с расширенным логом.
   - **Панель быстрых клавиш ввода:**
     - `✅ 1 (Proceed)` — мгновенно отправляет `1` и `Enter` для подтверждения действия в Codex/Claude;
     - `y (Yes)` — отправляет подтверждение `y` и `Enter`;
     - `❌ Esc` — отменяет диалог или закрывает тултип;
     - `🛑 Ctrl+C` — прерывает зависшую команду;
     - `⚡ /compact` — отправляет команду ручного сжатия контекста.
   - **Строка ввода `>`**: позволяет отправить произвольную команду агенту через защищённый вызов `POST /api/send`.

---

## 5. Контроль нагрева контекста и компакция

В верхней полосе дашборда выводится сводный статус контура:
- Если любой узел превышает **75% CTX**, в шапке появляется предупреждающая кнопка:  
  `⚡ rig compact <seat> (<pct>%)`.
- Клик по кнопке копирует точную команду в буфер обмена для безопасного запуска компакции на границе слайса.
