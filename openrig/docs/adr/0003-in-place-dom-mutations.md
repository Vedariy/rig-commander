# ADR-0003: In-place DOM Patching при автообновлении

- **Статус:** `[ACCEPTED]`
- **Дата:** 2026-11-05
- **Контекст:** Предотвращение мерцания интерфейса, потери фокуса ввода и сброса CSS-анимаций при регулярном опросе телеметрии.

---

## 1. Контекст и проблема

Дашборд опрашивает `/api/telemetry` каждые 4 секунды.
При наивной реализации через регулярное пересоздание DOM (`container.innerHTML = renderAll()`):
1. **Сброс фокуса ввода:** Если оператор набирает команду в строке ввода мини-терминала паспорта узла, каждое автообновление сбрасывает фокус и стирает набранный текст;
2. **Прерывание анимаций:** Индикаторы пульсирующего сердца (`❤️`) у работающих агентов и плавающие буквы сна (`Zzz...`) перезапускают CSS-анимации, вызывая неприятное визуальное мерцание;
3. **Сброс позиции скролла:** Скролл внутри логов tmux и списка задач сбрасывается в верхнюю позицию;
4. **Отказ кликов:** Клик мышью по узлу в момент перерендера теряется браузером.

## 2. Принятое решение

Внедрить гибридный двухфазный рендеринг в функции `renderTopology()`:

1. **Фаза проверки структуры:**
   Сравнивается количество существующих DOM-элементов узлов `.agent-node` с размером массива `AGENTS`.
   - Если количество изменилось (добавлен новый агент или удалён узел) — выполняется полный чистый рендер слоя узлов.
   
2. **Фаза In-place патчинга (когда набор узлов стабилен):**
   Существующие DOM-узлы **не пересоздаются**, а обновляются точечно по месту через прямое изменение свойств:
   ```javascript
   el.className = `agent-node state-${agent.state} ...`;
   el.style.left = `${agent.x}%`;
   el.style.top = `${agent.y}%`;
   el.style.setProperty('--ctx-color', thermal.color);
   el.style.setProperty('--ctx-glow', thermal.glow);
   
   // Обновление LED-индикатора только если изменилось состояние
   if (ledEl.getAttribute('data-state-key') !== `${agent.state}:${agent.activityLabel}`) {
     ledEl.innerHTML = renderStateIndicatorHtml(agent);
     ledEl.setAttribute('data-state-key', `${agent.state}:${agent.activityLabel}`);
   }
   ```
3. **Сохранение состояния инпута паспорта:**
   При вызове `renderInspectorAndScorecards()` запоминаются `prevInput.value` и факт наличия активного фокуса (`document.activeElement === prevInput`). После обновления карточки паспорта набранный текст и фокус мгновенно восстанавливаются.

## 3. Последствия

### Плюсы:
- Абсолютно стабильный UI: ни один клик не пропадает, текст в терминальном инпуте не стирается при автообновлении;
- Непрерывные CSS-анимации пульсации и сна без микро-лагов и дёрганий;
- Низкая утилизация CPU: браузер меняет только точечные текстовые узлы и CSS-классы, не пересчитывая всё дерево layout.
