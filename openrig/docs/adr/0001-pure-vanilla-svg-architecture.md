# ADR-0001: Pure Vanilla JS + SVG Canvas (Zero-Build Архитектура)

- **Статус:** `[ACCEPTED]`
- **Дата:** 2026-11-04
- **Контекст:** Разработка HUD / Дашборда мониторинга мульти-агентного рига OpenRig.

---

## 1. Контекст и проблема

Для наблюдения за автономным роем агентов OpenRig оператору требуется дашборд с высокой плотностью информации: интерактивная карта топологии, Sankey-магистрали очередей, живые экраны терминалов `tmux`, радар блокеров и аналитика выгорания контекста.

Традиционный стек (React, Next.js, Vite, Tailwind, Webpack) несёт значительные накладные расходы:
- Необходимость сборки (`npm run build`, `npm run dev`), долгое поднятие dev-сервера;
- Разрастание `node_modules` (сотни мегабайт сторонних зависимостей);
- Хрупкость окружения при фоновом запуске на хосте разработчика;
- Риск расхождения версий и конфликтов бандлера.

## 2. Рассмотренные альтернативы

1. **SPA на React / Next.js:** Удобная компонентная модель, но требует компиляции, утяжеляет рантайм и делает невозможным открытие файла двойным кликом (`file://`).
2. **Готовые BI-системы (Grafana / Prometheus):** Не поддерживают интерактивный ввод в терминалы `tmux`, кастомные Sankey-магистрали с динамическим числом задач и специфическую семантику OpenRig (HELD, PARKED, Zzz...).
3. **Pure Vanilla HTML5 / CSS3 / JavaScript + векторный SVG Canvas:** Единый легковесный файл `index.html`, использующий современные стандарты веба (CSS Variables, Flexbox/Grid, SVG маркера и лучи, Fetch API).

## 3. Принятое решение

Принято решение реализовать клиентскую часть дашборда на **чистом Vanilla JavaScript без сторонних фреймворков и бандлеров**:
- Всё оформление построено на нативных CSS-переменных (`--cyan`, `--emerald`, `--crimson`, `--bg-card`);
- Топология отображается гибридно:
  - Интерактивные HTML-карточки агентов с абсолютным позиционированием (`left: X%`, `top: Y%`);
  - Векторные магистрали очередей рисуются через нативный `<svg>` с динамическим расчётом точек выхода луча из границ карточки;
- Страница может открываться как автономно (`file://index.html` в Snapshot Mode), так и в связке с локальным сервером телеметрии (`http://127.0.0.1:7440`).

## 4. Последствия

### Плюсы:
- **Мгновенный отклик и запуск:** Время старта 0 миллисекунд. Любая правка вступает в силу сразу после сохранения файла и нажатия F5 в браузере.
- **Нулевые зависимости на клиенте:** Нет риска уязвимостей в цепочке npm-пакетов, нет необходимости запускать `npm install`.
- **Максимальная производительность:** Браузер исполняет чистый нативный код без виртуального DOM и оверхеда фреймворков.

### Минусы и ограничения:
- Компонентная верстка и HTML-шаблоны генерируются шаблонными строками ES6. Требуется строгая дисциплина экранирования ввода (`escapeHtml`).
