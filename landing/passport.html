RigCommander // Neural Command Deck

Локальная DSS SA-система управления автономным флотом AI-агентов (OpenRig / Universal tmux & JSONL). Объединяет адаптивный граф (Динам/Фикс + X-Ray у курсора), операционную онтологию v2.2, 3-уровневый AI Evaluator (Advisory-Only), граф общего контекста задач (`blockedOn` + `body` + `RECAP.md`), поддорожечный Гант + Handoff Flow, FinOps, Remote Mobile PWA и идемпотентный HITL write-back.

1. Чистый слой domain & ontology Все 16 модулей assets/domain/ и слой assets/ontology/ не обращаются к DOM/window и импортируются напрямую в node --test.
2. Единый источник правды Правки вносятся только в openrig/ и landing/; папка public/ генерируется командой npm run sync:public.
3. Неблокирующая аналитика FleetIntelligenceEngine принимает снапшоты через setImmediate с изоляцией сбоев 6 детекторов и шумоочисткой.
4. Действия по причине и с защитой Все UI-поверхности берут кнопки из actions.js; у здорового idle-узла 0 write-back кнопок; двойные клики гасятся ActionFlightGuard + 409.
